Lazy Apply

Fills job applications with Gemma running on your own laptop. Asks before anything sensitive. Hands you the parts only you should do. Never clicks Submit.

Demo video coming soon.

What it does on every application

Fills it for youName, contact, links, location, current role and your CV upload, straight from your profile.
Asks you firstSalary, visa and diversity questions, consent boxes and drafted answers wait for one click.
Hands it to youCAPTCHAs, passwords and extra uploads are outlined on the page. It notices when you're done.

Install

  1. Install Ollama and get the model: 
    ollama pull gemma3:4b-it-qat
  2. Let browser extensions talk to Ollama (macOS shown; the extension shows Linux and Windows steps), then restart Ollama: 
    launchctl setenv OLLAMA_ORIGINS "chrome-extension://*"
  3. Build the extension: 
    pnpm install && pnpm build
  4. In Chrome, open chrome://extensions, turn on Developer mode, choose Load unpacked, and pick extension/output/chrome-mv3.

Promises, enforced in code

  • Your CV, profile and answers stay in your browser. The model runs on localhost; the extension can't connect anywhere else.
  • It never clicks Submit, never types passwords, never solves CAPTCHAs, never creates accounts.
  • Text on job pages is treated as data, so a posting can't instruct it.
  • No analytics, no telemetry, no account. This page doesn't track you either.
